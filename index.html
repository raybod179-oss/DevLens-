هر تحلیل یک مسیر مشخص را طی می‌کند؛ بنابراین نتیجه فقط یک پیام قرمز نیست، بلکه یک تشخیص واقعی است.

تشخیص

نوع خطا و زبان یا فریم‌ورکی که خطا به آن مربوط است را شناسایی کن.

مکان‌یابی

فایل، خط و ستون را مستقیماً از Stack Trace استخراج کن.

توضیح

علت احتمالی را با زبان فنی یا به زبان ساده توضیح بده.

رفع

یک قدم عملی برای رفع مشکل و در صورت امکان نسخه اصلاح‌شده کد دریافت کن.

تحلیل

درباره

DevLens چیست و چه چیزی نیست؟

DevLens یک پلتفرم برای دیباگ و ابزارهای توسعه‌دهندگان است. یک خطا، Stack Trace یا قطعه‌ای از کد را دریافت می‌کند و همیشه یک مسیر مشخص را طی می‌کند: تشخیص زبان و نوع خطا → پیدا کردن مشکل → توضیح علت → پیشنهاد راه‌حل.

طراحی شده بر پایه قوانین

نسخه اول DevLens کاملاً روی یک موتور قوانین محلی اجرا می‌شود؛ مجموعه‌ای ماژولار از الگوها برای خطاهای رایج JavaScript، TypeScript، React، Vue، PHP، Laravel، Node.js، Python، Java، C#، SQL، JSON و Git. بدون API خارجی، بدون API Key و بدون نیاز به درخواست شبکه.

ساخته شده برای رشد

معماری پروژه امکان اضافه شدن حالت تحلیل با کمک هوش مصنوعی را در آینده فراهم می‌کند، بدون اینکه بخش‌های دیگر برنامه به آن وابسته باشند. اگر چنین حالتی اضافه شود، کلید API پشت Backend یا Serverless Function قرار خواهد گرفت و هرگز داخل Frontend قرار نمی‌گیرد.

اصول

01
حریم خصوصی اولویت دارد. کدها و خطاهای شما در مرورگر پردازش می‌شوند و تا زمانی که خودتان حالت AI را در نسخه آینده انتخاب نکنید، به سروری ارسال نمی‌شوند.
02
توضیح ساده، در صورت نیاز. گزینه «توضیح ساده» علت فنی را به یک جمله قابل فهم تبدیل می‌کند.
03
ماژولار. قوانین، ابزارها و پشتیبانی از زبان‌ها به شکلی طراحی شده‌اند که بتوانند مستقل از یکدیگر توسعه پیدا کنند.
DevLens — مستقیماً در مرورگر شما اجرا می‌شود. هیچ خطا یا کدی که وارد می‌کنید به سرور ارسال نمی‌شود.
